OFFSCRIPT ⚡️

Life happens when you go Off-Script.

This repository contains the landing page and waitlist funnel for Offscript, a social curation platform for Delhi NCR that connects strangers into "Pods" for concerts, comedy, and workshops.

🚀 The Mission

We are solving "Social Friction."
How many times have you missed a concert because your friends flaked? Offscript curates groups (Pods) of 3-5 verified people so you never have to miss out on an event again.

Current Phase: Phase 1 (Alpha) - Manual Curation & Demand Validation.

🛠 The Tech Stack (Zero-Build Architecture)

To keep development rapid and costs at zero, this project uses a Single File Component architecture. No node_modules, no complex build steps.

Core: React 18 & ReactDOM (via CDN)

Styling: Tailwind CSS (via CDN)

Transpiler: Babel (via CDN for in-browser JSX compilation)

Icons: Lucide React (Inline implementation)

Deployment: GitHub Pages / Netlify

📂 Project Structure

It's just one file. Seriously.

/
└── index.html  <-- Contains HTML, CSS Config, and React Logic


⚡️ Quick Start

Since there are no dependencies to install:

Clone the repo

git clone [https://github.com/ashwanikumar1499/offscriptWaitlistpage.git](https://github.com/ashwanikumar1499/offscriptWaitlistpage.git)


Run it
Simply double-click index.html to open it in your browser.

🌐 Deployment

This project is optimized for instant deployment on GitHub Pages or Netlify Drop.

Go to Settings > Pages in this repository.

Select main branch as the source.

Click Save.

Your site will be live at https://ashwanikumar1499.github.io/offscriptWaitlistpage/
